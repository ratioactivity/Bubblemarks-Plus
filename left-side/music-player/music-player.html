Troubleshoot refreshed timestamps

Hydrophones not working? Timestamps probably got refreshed. Try this:

  1. Go to the following link. Change "rpi_orcasound_lab" to match whatever hydrophone you are using (ex. "rpi_sunset_bay").
    https://audio.orcasound.net/rpi_orcasound_lab/latest.txt

    This will download a .txt file.

  2. Open that .txt file. It will return something like "1732749200".
    1732749200
  3. Build the stream URL.
    https://audio.orcasound.net/rpi_HYDROPHONE_NAME/hls/TIMESTAMP/live.m3u8

Update URLs in code.
